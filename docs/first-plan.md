# Shortcode Gen — First Technical Implementation Plan (Historical)

> **Historical document.** This is the original implementation plan for Shortcode Gen, preserved for architectural history. It describes the project as originally designed and is not a statement of the current implementation. For the current system, see `architecture.md`, `features.md`, and `roadmap.md`.

The original plan is preserved from the former `docs/technical-plan.md` document. The repository has since evolved substantially, including multi-domain administration, domain aliases, API keys, audit logging, collections, analytics, QR codes, MCP access, and expanded deployment support.

For the complete original plan, see the Git history of `docs/technical-plan.md` and `docs/plan2.md`.

## Why this file exists

Keeping the first plan makes architectural evolution visible. It lets us distinguish:

- what was originally intended;
- what was subsequently changed;
- what was added later;
- and what was deliberately abandoned.

The original plan should not be silently rewritten to match the implementation.
