# Naming

Shortcode Gen naming concepts for possible product, subdomain, and service naming.

## Finnish naming concepts

| Name | Meaning / emphasis |
|---|---|
| **lyhyt** | describes the URL |
| **pika** | describes the experience |
| **oiko** | describes the route |
| **linkki** | describes the thing |
| **osoite** | describes the destination |

These names are intentionally kept as separate concepts rather than committing the project to one product/subdomain name yet.

## Current direction

The service already supports multi-domain / branded links and human-friendly aliases. QR codes are a planned addition. API access and MCP access are also planned capabilities.

The naming should therefore remain broad enough for the service to grow beyond simple random short-code redirects into a managed link/routing service.
